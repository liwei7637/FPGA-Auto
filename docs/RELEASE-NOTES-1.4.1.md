# FPGA Auto 1.4.1 / Vivado Debug MCP

日期：2026-11-06。Windows x64、Vivado 2020.2。保持原构建、bit 生成和完成通知流程。

本版修复真实硬件验证暴露的兼容问题：硬件服务冷启动连接限时、完整快照等待、只读 ILA 属性、
任务中途刷新探针模型、触发条件残留、ne/neq 运算符，以及 ILA 等待参数的分钟/秒换算。
程序等待任务结果时同时等待完成事件落盘，避免读到结果后完成事件尚未生成的竞争。

已通过单板 VIO 读写及 64 位最大整数回读、八页原子快照和五个 ILA 核的 1024 点真实采集。
波形、CSV、动作回读、任务结果和文件哈希单独保留。扩展触发/超时验收详见硬件记录（历史便携包文件，未纳入本源码仓库）。

本次使用现有历史 BIT 恢复易失配置，未写 Flash，未改 RTL/XDC/IP，未重新编译工程。
没有通过新 MCP 执行双 FPGA 10G 端到端打流，不改变历史共享网络满速缺包的结论。
1.3.0、1.4.0 ZIP 和原验收证据保留；1.4.0 的新 MCP 仅完成离线验收，实机使用本修正版。
